# dsh-brand-identity · 品牌设计体系参考

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-brand-identity
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-brand-identity"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-brand-identity
```

> 安装即在本机运行第三方代码，请自行审阅源码。
